# VRFusion

**Универсальное приложение‑мост** между ПК (Windows) и телефоном Samsung S21 FE, которое делает телефон «глазами» и микрофоном для VR, а Kinect 360 — трекером тела.  

## Что входит в пакет
- **Android‑приложение** (Kotlin) – захватывает видеопоток, IMU‑данные, аудио и отправляет их по UDP/WS в ПК.
- **PC‑сервер** (C# .NET 6) – получает поток, декодирует видео (FFmpeg), объединяет IMU‑данные с позицией от Kinect 360 (driver4vr), применяет комплементарный‑фильтр для удаления дрейфа, отправляет данные в OpenVR как *Custom Tracker* и создает виртуальный микрофон.
- **Поддержка геймпада** (XInput) – может использоваться как контроллер VR.
- **Настраиваемый**: звук и микрофон можно включать/выключать через UI в Android‑приложении.

## Как собрать и запустить
### Требования
| Платформа | Требования |
|-----------|------------|
| **ПК (Windows)** | .NET 6 SDK, FFmpeg (в PATH), driver4vr + OpenVR (SteamVR), Visual Studio 2022 (или `dotnet build`). |
| **Android** | Android Studio Beta 2024+, SDK ≥ 24, Kotlin, разрешения CAMERA, RECORD_AUDIO, INTERNET. |

### Шаги
1. **Клонируйте репозиторий**
   ```bash
   git clone <repo‑url> f:/source/repos/VRFusion
   ```
2. **Соберите сервер**
   ```bash
   cd f:/source/repos/VRFusion/PCServer
   dotnet build -c Release
   ```
   Запустите `VRBridgeServer.exe`.  Сервер автоматически определит IP‑адрес ПК (192.168.31.2) и будет ждать соединения от телефона.
3. **Соберите Android‑приложение**
   - Откройте проект `AndroidApp` в Android Studio.
   - Установите SDK‑платформу 33 (Android 13) или выше.
   - В `VRBridgeService.kt` измените `remoteAddr` на IP ПК, если требуется.
   - Сгенерируйте APK и установите на телефон.
4. **Запуск**
   - Запустите сервер на ПК.
   - Запустите приложение на телефоне (foreground‑service). Оно отправит «handshake» с IP‑адресом телефона (192.168.31.6).
   - В SteamVR появится виртуальный дисплей и трекер **VRFusion Tracker**.
   - При желании включите звук/микрофон в Android‑UI.

## Конфигурация
Файл `config.json` (PCServer) хранит порты и IP‑адрес телефона. По‑умолчанию:
```json
{
  "phone_ip": "192.168.31.6",
  "imu_port": 6000,
  "audio_port": 6002,
  "video_port": 6004,
  "osc_port": 9000
}
```
Можно изменить и перезапустить сервер.

## Как работает коррекция дрейфа
- **IMU** от телефона → кватернион (гипер‑параметры).
- **Kinect 360** через driver4vr → позиция тела (скелет).
- **Комплементарный фильтр** (α ≈ 0.98) объединяет быстрые изменения от гироскопа и медленную корректировку от акселерометра + фиксированную позицию от Kinect, устраняя накопление ошибки.
- Результат отправляется в OpenVR как *Custom Tracker* (OSC / VRPN).
